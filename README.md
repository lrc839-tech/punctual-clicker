# 准点点击器

一个本地运行的 Mac 定时点击工具。框选按钮区域，设置北京时间的整分时刻、总点击频率和次数；每次在区域内随机落点，可选单区域或 A、B 双区域轮流点击。可先测量输入延迟，再提前发送点击来补偿稳定延迟。适用于普通 Mac 窗口，也可配合苹果「iPhone 镜像」使用。

**下载安装包即可运行，不需要 AI、Python、Node.js、Xcode 或其他运行环境。** 手机校准网页和原生校准服务均内置于 App。首次使用仍需由使用者授予 macOS 辅助功能权限。

## 下载与安装

在[最新发行版](https://github.com/lrc839-tech/punctual-clicker/releases/latest)中下载 `PunctualClicker-版本号-macOS-universal.dmg`，打开后把「准点点击器」拖到「应用程序」，再从「应用程序」启动。也提供包含同一 App 的 ZIP 包；GitHub 自动生成的 **Source code** 是源码，不是可直接运行的安装包。

当前发布包采用本地 ad-hoc 签名，**尚未使用 Developer ID 签名及 Apple 公证**。首次从互联网下载后，macOS 可能阻止启动；确认下载来自本项目且未被篡改后，由使用者按照[安装说明](docs/INSTALL.md)处理系统的首次打开提示。这与安装软件依赖无关。

| 使用方式 | 系统与硬件 |
| --- | --- |
| Mac 本机窗口点击 | macOS 13 或更高；Universal 包含 Apple Silicon 与 Intel 两种架构。Apple Silicon 已进行实际运行验证；Intel 仍需实机验证。 |
| 通过「iPhone 镜像」操作手机 | 还需满足苹果自身条件：macOS 15 或更高的 Apple Silicon 或带 T2 芯片的 Mac、iOS 18 或更高等。[Apple 官方要求](https://support.apple.com/en-us/120421) |

完整首次安装、权限、更新和卸载步骤见[安装说明](docs/INSTALL.md)。

## 开始使用

1. 把目标应用打开到需要点击的页面；手机目标先连接好「iPhone 镜像」。
2. 点击「开启辅助功能权限」，在系统设置中为当前安装的「准点点击器」开启权限，再回到工具。
3. 等待启动时的 NTP 授时完成，也可点击「校准北京时间 · NTP」。状态栏会显示来源、本机快慢、RTT、估计不确定度和授时年龄。
4. 选择「单区域」或「双区域轮流」，点击「框选区域 A」拖框选中按钮内部。双区域模式再点击「框选区域 B」，框选同一窗口内的另一个按钮；圈选期间按 Esc 可取消并保留原选择。
5. 选择日期、小时和分钟。秒固定为 `00`；「下一个整分」会选择当前北京时间之后的下一分钟。
6. 设置「总频率」「总点击数」和提前补偿，核对界面显示的执行计划，再点击「开始等待并点击」。等待或执行期间，点击「立即停止 · Esc」或按 Esc 可停止。

普通任务每次都在所选矩形内重新随机取点；同一次按下与抬起使用同一点。双区域从 A 开始，按 A → B → A → B 轮流执行。A、B 必须位于同一目标窗口；重新框选 A 时若换了窗口或窗口尺寸变化，B 会被清空，需重新选择。切回单区域后只使用 A。

开始前确认目标窗口的位置、大小和页面。执行期间切换应用、移动窗口或让设备休眠，可能触发停止保护。工具只安排鼠标输入，不判断第三方页面的业务状态，也不保证抢票、排队或其他业务结果。

## 参数

| 参数 | 含义 |
| --- | --- |
| 北京时间 | 固定使用 `Asia/Shanghai`；只选择日期和时分，实际目标为该分钟的 `00.000` 秒。 |
| 点击模式 | 单区域在 A 内随机落点；双区域按 A、B 轮流，每次在对应区域内随机落点。 |
| 总频率 | 全部点击合计每秒 0.1～100 次，双区域不分别计频率。计划节拍从同一时间基准计算，不累加前一次点击的实际延迟。 |
| 总点击数 | 全部实际点击合计 1～10000 次，不是轮数；奇数时 A 比 B 多一次。只点一次就填 1。普通任务还受授时有效期限制。 |
| 提前补偿 | 单位毫秒，正数提前、负数延后，范围 −5000～5000。应使用当前路径的实测值。 |
| 按住 | 按下到抬起的计划时长，默认 8 毫秒，范围 0.5～500；多次点击时须短于相邻点击间隔。 |

例如双区域设为 `5 次/秒、5 次`，执行顺序为 A → B → A → B → A：A 3 次、B 2 次，相邻点击间隔 200 毫秒，首末计划时刻相隔 0.8 秒。

校准以**鼠标抬起（mouseUp）到达接收端**为完成口径。目标为 `T`、补偿为 `D`、按住时长为 `H` 时，计划在 `T−D−H` 按下、`T−D` 抬起。若目标应用在按下时就触发操作，抬起口径不能直接证明它的触发时刻。

如果某次已经按下，停止时仍需释放鼠标；该次可能已触发目标动作。停止不能撤销已经发生的动作。明显迟到时，工具会停止后续点击，不集中补发。

## 北京时间与 NTP

默认查询 `ntp.aliyun.com`、`time.cloudflare.com` 和 `time.apple.com`。公共 NTP 无需账户或会员；[阿里云](https://help.aliyun.com/en/ecs/user-guide/alibaba-cloud-ntp-server/)与 [Cloudflare](https://developers.cloudflare.com/time-services/ntp/)均提供免费公共授时。网络需允许 DNS 和 UDP 123，代理、防火墙和丢包会影响查询质量。

程序根据多轮响应估计时间偏差，建立 UTC 与本机单调时钟的映射，再按北京时间显示和安排普通任务。它不修改 macOS 系统时间，也不需要管理员权限来校时。多来源一致时明确标注；只有一个来源合格时标为「单源，未交叉验证」，无法形成一致结果时拒绝授时。

当前有效性规则：

- 一次授时有效期为 120 秒，并按假定 50 ppm 本机漂移增加不确定度估计。这是软件预算，不是已证明的硬件误差上限。
- 估计不确定度超过 100 毫秒或授时过期时，不能用于普通定时任务。
- 开始时优先使用年龄小于 30 秒的有效结果，否则先刷新。远期任务在首次按下前约 30 秒再刷新，失败便停止，不悄悄改用系统时间。
- 授时后，首次按下须在 350 毫秒至 48 小时以内；整轮点击的最后一次释放也须落在同次授时的有效期内。连点跨度过长时需减少次数或提高频率。
- 取消、退出和休眠会停止任务；晚到的校时结果不会重新启动已取消的任务。休眠后需要重新授时。

当前采用普通 NTP，没有实现 NTS 加密认证。RTT/2、服务器报告参数、来源差异和漂移预算形成的**估计不确定度不是严格误差上限**，也不代表达到 ±1 毫秒。

## 测量并补偿点击延迟

### Mac 本机

点击「② 本机校准 · 30 次」，工具会打开绿色接收窗口并发送真实系统点击。保持测试窗口在前台，收齐后点击「采用实测补偿」，再用「本机验证补偿」运行另一组。该结果不包含手机镜像传输延迟。

### iPhone 镜像

1. Mac 和 iPhone 接入同一局域网。在工具中点击「手机镜像校准…」，启动内置服务并查看本机网址。
2. 在 **iPhone Safari** 打开该网址，等待网页完成 20 轮对时。
3. 锁定手机，在 Mac 的「iPhone 镜像」中保持 Safari 测试页在前台。
4. 用「框选区域 A」圈选镜像页面的蓝色校准靶区，点击「镜像采样 · 30 次」。校准固定点击 A 的中心，不使用随机落点或 B；首次会先做一次单击锚定，再自动采集 30 次正式样本。
5. 收齐有效回执后采用补偿，再用「镜像验证补偿」运行另一组。期间不要手动点击靶区、移动窗口或切换页面。

手机网页只负责记录接收；真实点击由 Mac 点击器发出。网页通过对时把手机时间映射到 Mac 的原始时钟，发送记录和接收记录使用同一基准，避免把 NTP 修正混入链路延迟。手机对时有效期为 60 秒，新轮次遇到超过 40 秒的旧结果会提前刷新；这与 120 秒的 NTP 授时有效期是两项独立校准。

测试测到的是 **Mac 发出 mouseUp 请求 → 手机 Safari 的 pointerup 回调**。它不是触屏硬件采样时刻，也不是大麦、券商或其服务器收到业务指令的时刻。补偿能抵消稳定部分，不能消除无线传输、系统分发和接收处理的变化；本工具不承诺严格 ±1 毫秒或任何第三方业务成功率。

## 数据与网络

- 运行报告保存在 `~/Library/Application Support/PunctualClicker/Reports`，更新 App 不会覆盖此目录。
- 普通任务报告记录框选区域、每次实际落点及 A／B 标识；校准报告仍按固定点记录。窗口遮挡保护检查本次实际点击点。
- 手机校准服务仅在使用该功能时启动，端口为 `18765`，退出工具后停止。服务与手机通过当前局域网通信；不要将此端口转发到公网。
- NTP 查询会访问公共授时服务器。程序不会将点击坐标或校准报告上传到云端。
- 发布包和源码不包含开发时的个人运行报告；每台设备应重新测量自己的延迟。

## 源码构建与开发测试

使用发布包不需要开发工具。只有自行修改、构建源码时，才需要 macOS 与 Apple Command Line Tools 中的 Swift 编译器。

```sh
./build.sh
```

默认输出 `build/准点点击器.app`，不会替换正在使用的安装副本。需要安装到当前用户的应用目录时，显式运行：

```sh
./build.sh --install
```

制作 Universal DMG、ZIP 和 SHA256 校验文件：

```sh
./scripts/package-release.sh
```

输出位于 `dist/`。当前发布包的签名／公证状态由发布说明明确列出；自行构建不等于已获得 Apple 公证。

开发测试入口为 `./run-tests.sh`。Swift 测试覆盖授时与调度，历史 Python 校准服务及其回归测试保留作开发参考；完整测试脚本包含这些 Python 测试，因此开发机需要 Python 3。**Python 不在发行 App 的运行链路中。** 调度基准使用空发送器，不能当成真实桌面或手机接收精度的证明。
