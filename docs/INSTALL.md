# 安装与首次使用

「准点点击器」是一个独立 Mac App。发行包已包含手机校准网页和原生服务，不需要 AI、Python、Node.js、Xcode 或额外运行环境。

## 安装

1. 从本项目的 GitHub **Releases** 下载名称包含 `universal.dmg` 的发布包。
2. 双击 DMG，将「准点点击器」拖到「应用程序」快捷方式。
3. 推出 DMG，再从 Mac 的「应用程序」启动「准点点击器」。后续固定使用这个安装副本。

也可下载 `universal.zip`，解压后将其中的 App 移到「应用程序」。只需分发 DMG 或 ZIP 中的一种；无需连同源码或其他目录一起发送。

软件的本机窗口点击功能要求 macOS 13 或更高。Universal App 包含 Apple Silicon 与 Intel 两种架构；Apple Silicon 已实际运行验证，Intel 尚待实机验证。

## 首次打开的系统提示

当前发布包采用 ad-hoc 签名，尚未使用 Apple Developer ID 签名及公证，因此通过互联网下载后可能出现开发者无法验证等提示。这个版本不能承诺在全新 Mac 上免确认打开。

确认软件来自本项目、下载未损坏后，由电脑使用者按以下步骤处理：

1. 先尝试从「应用程序」打开一次，查看系统提示。
2. 打开「系统设置 → 隐私与安全性」，向下找到对应 App 的提示。
3. 如果系统提供「仍要打开」，确认所指的是「准点点击器」后选择它，再按系统提示确认打开。

这是 [Apple 官方说明](https://support.apple.com/en-us/102445)中的人工首次打开流程。公司或学校管理的 Mac 可能由管理员限制此选项；此时需联系该设备管理员。如果提示软件损坏或下载校验不一致，重新下载并核对发布包，不要关闭系统安全保护。

## 开启鼠标控制权限

1. 在工具中点击「开启辅助功能权限」。
2. 按系统提示进入辅助功能／设备控制权限设置，为安装在「应用程序」中的「准点点击器」开启权限。
3. 回到 App，确认显示「辅助功能权限已开启」。必要时退出再重新打开。

权限只能由这台电脑的使用者在 macOS 中授予，不能随安装包预先授权。它允许 App 模拟鼠标输入，是实际点击所需的系统权限。

若更新后开关已开启但 App 仍不识别，先退出 App，在该权限列表移除旧条目，再添加当前安装的 App 并开启，然后重新启动。不要添加 DMG 中或下载目录里的临时副本。

公开 ad-hoc 包更新后代码指纹会变化，可能需要重新授权；本机固定开发签名通道则复用已配置证书并检查身份兼容性。应以当前 App 内显示的权限状态为准。确实失效时，移除旧条目后重新添加准确安装路径；系统身份验证由使用者本人完成。

这不是权限状态刷新慢。macOS 根据代码签名的 designated requirement 识别已授权程序；ad-hoc 签名绑定特定版本的代码指纹，重新编译后原授权可能不再匹配。长期方案是持续使用同一持久签名身份与兼容的代码身份。公开分发应采用 Developer ID；固定自签名证书仅可用于本机开发测试，不能代替 Developer ID 或 Apple 公证。见 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

源码安装流程已增加代码身份兼容检查：`./build.sh --install` 默认拒绝会破坏原身份的替换，避免每次编译后静默让旧授权失效。仅在明确迁移签名身份、接受重新授权时，才使用 `--allow-identity-change`。

本机内部开发可在本人明确同意后运行一次 `zsh scripts/setup-local-signing.sh --create`，在登录钥匙串创建固定的“准点点击器本机开发”代码签名身份；不修改系统信任设置。私钥不进入项目、安装包或 GitHub。配置位于 `~/Library/Application Support/PunctualClicker/Signing`，之后普通本机构建自动复用，缺失或不可用时不会静默回退临时签名。不要删除该身份或每次重新创建证书。

公开打包使用 `--distribution` 通道，拒绝本机自签名开发身份。已使用本机固定身份的安装副本，后续应继续通过本机构建更新；用公开临时签名包覆盖它会再次切换身份。

## 设置第一次点击

### 使用大麦方案前

0.6.0 的大麦三键模式使用辅助功能权限发送鼠标并拦截键盘，不截图或识别页面，因此不需要屏幕录制权限。系统若拒绝启用键盘拦截，会明确提示并停止，不会静默退回无法拦截的键盘监听。首次授权仍由使用者本人完成。

先在手机大麦预填场次、票档、张数与观演人，再框选同一镜像窗口内三个实际按钮：1 底部购买／确定／提交、2 努力刷新、3 继续尝试。不用选机型；三区使用镜像窗口内坐标，平移后自动跟随，明显缩放后重新框选。透明数字和橙色框显示键位，当前执行区为青色亮框；覆盖层穿透鼠标。可先用「打开三区测试台」练习，无需真实购票；关闭测试台后恢复手机三区。

分别设置三区频率；底部次数 0 表示持续，填具体次数则每轮到数暂停。按 1 重开底部；按住 2／3 切区，松开当前键回底部并重新计数。三个区域互斥、无排队、无补发。可立即启动或整分直接安排首击，首击补偿只用于定时首击。Esc 停止全部；本模式不判断页面，请在支付、验证、缺票等页面主动停止。

立即启动和三区测试台可设置「立即启动等待」：3000 毫秒表示按按钮后等待 3 秒，0 不额外等待；倒计时中按键只切换目的区域，不提前点击。整分启动使用独立的「整分首击提前」，不叠加这段测试等待。

### 单区／双区定时

1. 等待 App 自动校准北京时间。也可点击「校准北京时间 · NTP」手动刷新；需要网络允许 DNS 和 UDP 123。
2. 打开目标页面，选择「单区域」，点击「框选区域 A」，拖框圈选目标按钮内部。正常任务每次在框内随机落点。
3. 选择日期和时分；秒固定为 `00`。「下一个整分」可快速选择下一分钟。
4. 设置「总频率」和「总点击数」；只点一次时将总点击数设为 `1`。尚未测量输入延迟时，可先用 `0` 毫秒补偿进行本机校准。
5. 确认位置、时间和次数后，再点击「开始等待并点击」。

等待或执行期间，按 Esc 或点击「立即停止 · Esc」停止。执行时保持目标窗口位置、大小及页面稳定，并保持无遮挡；窗口保护不能识别所有系统级覆盖层。不要让电脑休眠。已经按下的鼠标仍会被释放，这一次可能已触发动作，停止不能撤销已经发生的操作。

## NTP 手机到点校验与挂单回执复盘

手机 Safari 打开「手机镜像校准…」提供的最新网址，刷新到新版网页。在镜像中保持蓝色靶区可见，使用「框选手机测试靶区」单独框选；不会覆盖已保存的大麦三区。选「15 秒后 NTP 单击校验」快速测试，或先设置未来整分再选「按所设整分校验」。

手机完成同一轮 NTP 基准的校时后，程序才准备单击。结果显示目标、Mac 发出、手机收到三个北京时间、误差及校时不确定度估计。手机先记事件时刻再回传，因此结果上传等待不计入点击送达延迟。这个终点仍是手机测试页，不代表券商受理；单次结果不会自动改变补偿。

「挂单回执复盘…」可记录已发生的业务回执。请完整输入三位毫秒时间，明确 .040 与 .400 的区别，并注明字段含义。默认不确认券商时钟可比；勾选只是你的声明，程序不会验证该时钟，也不会自动下单或采用补偿。

## 两个区域轮流点击

1. 选择「双区域轮流」，先框选 A，再点击「框选区域 B」选择同一窗口内的第二个按钮。
2. 总频率指所有点击合计的每秒次数，总点击数指全部实际点击次数，不是轮数。例如 `5 次/秒、5 次` 是 A → B → A → B → A，A 3 次、B 2 次，首末计划时刻相隔 0.8 秒。
3. 核对界面显示的 A／B 次数和间隔后开始。每次在对应区域内随机落点，按下和抬起使用同一点。

两个区域不能跨窗口。重选 A 换了窗口或窗口尺寸变化时，B 会清空；按 Esc 取消框选会保留原选择。切回「单区域」只使用 A。

## 配合 iPhone 镜像

使用苹果「iPhone 镜像」还需符合其自身要求，包括 macOS 15 或更高的 Apple Silicon 或带 T2 芯片的 Mac、iOS 18 或更高、两台设备使用同一 Apple 账户及双重认证，并开启 Wi-Fi 与蓝牙。具体条件及可用地区以 [Apple 官方说明](https://support.apple.com/en-us/120421)为准。

手机路径延迟校准：

1. Mac 和 iPhone 连到同一局域网，点击工具中的「手机镜像校准…」。
2. 在 iPhone Safari 打开工具当前显示的网址，等待自动对时完成。端口自动分配，重启 App 后请重新查看地址。
3. 锁定 iPhone，通过「iPhone 镜像」保持 Safari 校准页在前台。
4. 在点击器中用「框选区域 A」圈选蓝色靶区，运行「镜像采样 · 30 次」。校准固定使用 A 的中心，不会随机点击或交替使用 B。
5. 收齐有效样本后采用补偿，再运行「镜像验证补偿」检查另一组结果。

如果系统询问是否允许 App 使用本地网络或接受传入连接，手机校准需要该局域网通信权限。服务和网页均已内置，不需要安装 Python。无法访问时检查同网、网址、防火墙与本地网络权限；不要将服务端口转发到公网。

Safari 校准只测量这条输入链路，不能证明其他 App 或其业务服务器在同一时刻收到操作。每台设备和每次会话的延迟都可能变化，应重新校准，而不是沿用其他人的补偿数值。

## 更新、报告与卸载

更新前先退出 App，再用新 App 替换「应用程序」中的旧版。运行报告保存在：

```text
~/Library/Application Support/PunctualClicker/Reports
```

更新不会覆盖这个数据目录。需要查看时，在访达选择「前往 → 前往文件夹」，输入上面的路径。

卸载时退出 App，将「应用程序」中的「准点点击器」移到废纸篓。若不再需要历史报告，也可自行删除上述数据目录；删除前先备份希望保留的记录。
